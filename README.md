# BMRF

A Minecraft Forge 1.12.2 mod that adds 432 BMRF decorative blocks.

## Requirements

- Minecraft 1.12.2
- Minecraft Forge 14.23.5.2847

## Building

```bash
./gradlew build
```

On Windows:

```bat
gradlew.bat build
```

The built mod jar is written to `build/libs/bmrf-1.0.0.jar`.
